## Задача 16

### Текст задачи

Первый массив, размерностью n x m, заполняется данными, вводимыми с клавиатуры, так что заполнение ведется по диагоналям параллельным побочной, начиная с левого верхнего угла. 
Второй массив, размерностью n x n, заполняется случайными числами из интервала [0;1] так, что выше побочной диагонали лежат числа больше 0.5, а на побочной диагонали и ниже — меньшие или равные 0.5.
Третий массив, размерностью n x n, заполняется для произвольного n так же, как для n=5:
<img width="245" height="162" alt="image" src="https://github.com/user-attachments/assets/17080d98-4718-4cb7-bbe1-a79240088fa7" />


### Алгоритм решения

1. Программа запрашивает у пользователя размерности `n` и `m` для первого массива. Заполнение происходит с клавиатуры с использованием цикла `while`, где переменная `sumIdx` (сумма индексов) идет от 0 до `(n - 1) + (m - 1)`. Внутри цикла проходим по строкам `i`, вычисляем столбец `j = sumIdx - i`. Если `j` попадает в границы, запрашиваем ввод.
2. Второй массив заполняется с помощью класса `Random`. Проверяется условие `i + j < n - 1` (нахождение выше побочной диагонали). Если true, генерируется число от 0.51 до 1.0, иначе — от 0.0 до 0.5.
3. Третий массив заполняется по диагоналям. Главная диагональ заполняется числами от 1 до n. Остальные диагонали (ниже главной) заполняются поочередно: нечетные по убыванию, четные по возрастанию, как на картинке в методичке.

# Задание 2

## Задача 16

### Текст задачи

Напишите программу, проверяющую можно ли в двумерном массиве найти такой столбец, который разбивает массив на два так, что сумма элементов в первом была больше суммы элементов во втором. Сам столбец в разбиваемые части не входит. Лишние переборы не допускаются.

### Алгоритм решения

1. Пользователь вводит размерность массива (n x m) и его элементы с клавиатуры.
2. Сначала вычисляется общая сумма всех элементов массива за один проход.
3. Заводится переменная `leftSum = 0`. Программа идет по столбцам слева направо (от 0 до `cols - 1`). Для текущего столбца считается его сумма `colSum`.
4. Сумма правой части вычисляется без лишних переборов: `rightSum = totalSum - leftSum - colSum`.
5. Если `leftSum > rightSum`, выводится номер столбца и поиск прекращается. Иначе `colSum` прибавляется к `leftSum`, и цикл идет дальше.

### Текст задачи

Вычислить значение матричного выражения `A + (B - 3 * C^T)`, используя перегрузку операторов. Перегрузить метод `ToString()` для вывода матрицы в виде таблицы.

### Алгоритм решения

1. Создан класс `Matrix`, содержащий приватное поле `int[,] _data`.
2. Реализован конструктор для инициализации матрицы из двумерного массива.
3. Перегружен метод `ToString()` с использованием `StringBuilder` для построчного вывода элементов с выравниванием (`PadLeft`).
4. Перегружены бинарные операторы:
   - `+` и `-` (поэлементное сложение и вычитание матриц с проверкой размерности).
   - `*` (умножение матрицы на скалярное число).
5. Написан метод `Transpose()` для получения транспонированной матрицы (C^T).
6. В методе `RunTask3` пользователь вводит размерности и элементы матриц A, B и C. Затем вычисляется выражение `A + (B - 3 * C.Transpose())` и выводится на экран.
